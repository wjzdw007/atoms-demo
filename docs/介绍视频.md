# 介绍视频是怎么做的

首页的 Atoms 介绍片长 1 分 40 秒、1080p，完全由代码生成，没有用视频编辑软件，也没有用第三方素材。新访客第一次打开首页时它会居中播放，关闭或播完后收到页面右下角的小按钮里，之后的访问不再打扰。源文件在 [video/](../video) 目录，可以一条命令重新生成。

## 内容与风格

- **事实来源**：全部取自 atoms.dev 的首页和 About 页面（2026 年 11 月访问）：产品定位、八个 AI 角色及其职责、Atoms Cloud 与 Race Mode、从 MetaGPT 到 MGX 再到 Atoms 的历程，以及 168K GitHub Stars、约 30 篇论文、170+ 国家和地区、1M+ 创造者这些数字。
- **叙事**：没有按功能清单平铺，而是讲一个人的处境：有想法、却只有一个人；然后团队出现；最后把想法做出来。
- **视觉**：跟官网保持同一种气质：浅色底、柔和的粉彩色块、黑色粗体字、蓝色强调、圆润的角色。
- **没有照搬的部分**：徽标和八个角色形象都是自己画的，旁白是自己写的，没有复制官网的徽标、角色图、截图或文案。片头角标和片尾都标明了这是应聘者自制的非官方介绍。

## 制作流程

1. **旁白先行**：`lines.txt` 里一行一句，逐句合成语音。成片用的是 Fish Audio 的克隆音色（复用了我另一个项目里的配音模块）；没有它时退回系统语音。
2. **按语音排时间线**：`timeline.mjs` 量出每句的时长，算出每句的起止时间和九个场景的分界。画面里每个动画的触发点都写成"第几句念到百分之多少"，所以换一句旁白或换一个音色，整片会自动重新对齐。
3. **画面是时间的纯函数**：`film.html` 暴露一个 `renderAt(t)`，给定秒数就画出那一帧，不依赖计时器或 CSS 动画。逐字出现的标题、角色的眨眼和跳动、旋转的点阵地球、彩带，都是由 `t` 算出来的。这让渲染可以乱序、并行，每次结果完全一致。
4. **逐帧渲染**：`render.mjs` 用无头 Chrome 开 5 个页面并行截图，约 3000 帧，两三分钟。
5. **声音**：`audio.cjs` 把每句旁白放到对应时间点，做响度归一，再叠一层很轻的合成和弦铺底。
6. **合成**：ffmpeg 把帧序列和音轨压成 H.264 / AAC 的 MP4，约 12MB。

```bash
cd video && npm i puppeteer-core @fontsource/ibm-plex-sans && ./build.sh
```

## 已知不足

- 铺底音乐是用正弦波合成的简单和弦，不是正式配乐。
- 制作过程中只能逐帧检查画面、用工具测量音量和时长，没有办法实际"听"成片，配音的语气需要人来把关。
