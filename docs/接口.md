# 接口说明

所有接口都在 `/api` 下，由 `src/app/api` 里的 Route Handler 实现。

## 约定

- **身份**：靠 httpOnly 的会话 Cookie（`atoms_session`）。没有 Cookie 的访客在第一次创建项目时自动得到一个访客账号。
- **归属**：项目相关的接口都校验项目属于当前用户；访问别人的项目一律返回 `404`，不区分"不存在"和"无权限"。
- **跨站保护**：所有非 `GET` 请求必须来自本站（校验 `Origin`，见 [src/proxy.ts](../src/proxy.ts)），否则返回 `403`。curl 等不带 `Origin` 的客户端不受影响。
- **请求与响应**：请求体和响应体都是 JSON。出错时响应为 `{ "error": "<给用户看的说明>" }`，配合下表的状态码。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数不对 |
| `401` | 没有会话 |
| `402` | 额度或积分不足 |
| `403` | 不允许（达到存储或数量上限、功能未开放、跨站请求） |
| `404` | 资源不存在，或不属于当前用户 |
| `409` | 冲突（项目正在生成、已有待确认订单） |
| `429` | 触发限流或当日上限 |
| `503` | 服务器忙（并发任务已满），或健康检查失败 |

## 项目

| 方法与路径 | 作用 | 请求体 | 成功响应 |
| --- | --- | --- | --- |
| `POST /api/projects` | 新建空项目（必要时创建访客） | `{ prompt }` | `{ id }` |
| `PATCH /api/projects/:id` | 重命名 | `{ title }` | `{ title }` |
| `DELETE /api/projects/:id` | 删除项目及其版本、对话、应用数据；正在运行的任务会被取消 | 无 | `{ ok: true }` |

## 生成

生成是后台任务：`POST` 只负责启动，进度通过 `GET` 读取。关掉页面不会中断任务。

| 方法与路径 | 作用 | 请求 | 成功响应 |
| --- | --- | --- | --- |
| `POST /api/projects/:id/generate` | 扣额度并启动任务 | `{ prompt, model? }`；竞速模式另传 `models: [id, …]`（2 到 3 个） | `{ ok: true, race }` |
| `GET /api/projects/:id/generate?from=N` | 从第 N 个事件开始回放，并持续推送到任务结束 | 无 | NDJSON 事件流；没有任务时 `204` |
| `DELETE /api/projects/:id/generate` | 停止任务 | 无 | `{ cancelled }` |

`model` 和 `models` 只能是服务端白名单（`LLM_MODELS`）里的模型，其他值会被忽略或拒绝。

事件流每行一个 JSON 对象（空行是保活心跳，应忽略）。事件类型定义在 [src/lib/types.ts](../src/lib/types.ts) 的 `AgentEvent`：

| `type` | 含义 |
| --- | --- |
| `stage` | 某个智能体开始或结束：`agent`、`status`、可选的 `note`；竞速时带 `lane` |
| `plan` / `review` | 产品计划、评审意见的文本增量 `delta` |
| `code` | 代码增量 `delta`；竞速时带 `lane` |
| `code_reset` | 工程师在按评审意见重写，丢弃已收到的代码 |
| `race_start` / `race_done` | 竞速开始（各路模型）与结束（候选列表） |
| `done` | 成功：新版本 `version`、对话消息 `message`、项目名 `title` |
| `error` / `cancelled` | 失败（带 `message`）或被停止 |

断线后带上已收到的事件数重新 `GET` 即可接上。服务重启会丢掉运行中的任务：重新 `GET` 会得到 `204`，对应的额度在启动时已自动退还，项目对话里会多一条说明。

## 竞速候选、版本、发布

| 方法与路径 | 作用 | 请求体 | 成功响应 |
| --- | --- | --- | --- |
| `POST /api/projects/:id/race` | 采用一个候选，保存为新版本，其余丢弃 | `{ candidateId }` | `{ version, message, html, title }` |
| `DELETE /api/projects/:id/race` | 放弃全部候选 | 无 | `{ ok: true }` |
| `GET /api/projects/:id/versions/:versionId` | 读取某个版本的 HTML | 无 | `{ html }` |
| `POST /api/projects/:id/versions/:versionId` | 恢复该版本（复制为一个新版本） | 无 | `{ version, message, html }` |
| `POST /api/projects/:id/publish` | 把最新版本发布到 `/s/<slug>`；`{ unpublish: true }` 取消发布 | 可选 `{ unpublish }` | `{ slug, versionId }` |
| `POST /api/share/:slug/remix` | 把一个已发布的应用复制到自己的工作区 | 无 | `{ id }` |

## 应用数据

生成的应用在沙箱里运行，自己不会调用这些接口；宿主页面把它的 `localStorage` 转存到这里。数据按「应用 + 用户」隔离。

| 方法与路径 | 作用 | 请求体 | 成功响应 |
| --- | --- | --- | --- |
| `GET /api/apps/:id/storage` | 读取当前用户在这个应用里的数据 | 无 | `{ data }` |
| `PUT /api/apps/:id/storage` | 整体覆盖保存 | `{ data: { key: value } }` | `{ ok: true }` |

应用的主人可以用自己的应用；已发布的应用任何人都能用，各存各的数据。

## 账号

| 方法与路径 | 作用 |
| --- | --- |
| `GET /api/auth/google` | 跳转到 Google 授权页 |
| `GET /api/auth/google/callback` | Google 回调：登录，或把当前访客原地升级为正式账号 |
| `POST /api/auth/logout` | 退出登录，并让这个账号的全部会话失效 |

## 额度与订单

| 方法与路径 | 作用 | 请求体 | 成功响应 |
| --- | --- | --- | --- |
| `GET /api/billing` | 今日免费次数、积分余额、套餐、最近订单 | 无 | `{ quota, orders, packs, mode, paymentNote, canPurchase }` |
| `POST /api/billing/orders` | 下单（需要 Google 登录，`BILLING_MODE` 不为 `off`） | `{ packId }` | `{ orderId, pack, mode, paymentNote }` |
| `DELETE /api/billing/orders/:id` | 取消自己还没付款的订单 | 无 | `{ ok: true }` |
| `POST /api/billing/orders/:id/pay` | 无需付款直接到账，仅 `BILLING_MODE=mock` 时存在 | 无 | `{ status, credits }` |

## 管理接口

需要请求头 `Authorization: Bearer <ADMIN_TOKEN>`。没有设置 `ADMIN_TOKEN` 时这些接口返回 `404`，等于不存在。

| 方法与路径 | 作用 | 成功响应 |
| --- | --- | --- |
| `GET /api/admin/orders` | 列出待确认的订单 | `{ orders }` |
| `POST /api/admin/orders/:id/settle` | 确认已收款并发放积分；重复调用不会重复发放 | `{ status: "paid" \| "already_paid" \| "over_limit" }` |

```bash
curl -H "Authorization: Bearer $ADMIN_TOKEN" https://your-domain.com/api/admin/orders
curl -X POST -H "Authorization: Bearer $ADMIN_TOKEN" https://your-domain.com/api/admin/orders/<订单号>/settle
```

## 健康检查

| 方法与路径 | 作用 | 响应 |
| --- | --- | --- |
| `GET /api/health` | 进程存活且数据库可读 | `200 { ok: true, jobs }`，`jobs` 是运行中的生成任务数；数据库不可读时 `503 { ok: false }` |

不需要登录，不返回任何用户数据。发布脚本用它判断新版本是否正常，也可以接到外部监控。
